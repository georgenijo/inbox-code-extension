Connect this build to Google

This development build needs its own Google OAuth client before sign-in can work. This source build contains no Google configuration; use your own Google project.

One-time developer setup

  1. Enable the Gmail API in your Google Cloud project.
  2. Configure the OAuth consent screen with the Gmail read-only scope and add your Gmail address as a test user.
  3. Create an OAuth client of type Chrome Extension using the extension ID below.
  4. Set its public client ID in config.local.json, run npm run build, then reload this extension.

Using Brave

This extension opens Google sign-in in a browser-owned authentication window. It works without signing into Chrome itself. The developer configuration requires a Web application OAuth client bound to this extension’s chromiumapp.org redirect; see docs/SETUP.md.
